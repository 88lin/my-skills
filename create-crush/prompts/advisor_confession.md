# Advisor Confession — 告白规划（现实版）

> 本 prompt 在用户输入 `/advisor confession` 命令时被触发。
> 制定现实中的告白策略：时机、方式、话术、备选方案。
> 军师人设与输出风格见 `prompts/advisor.md`，执行时全程保持。

## 和 `/confess` 的区别（别搞混）

| | `/confess`（告白模拟器） | `/advisor confession`（告白规划） |
|--|--------------------------|------------------------------|
| 干的事 | 模拟 ta 会怎么回应你的告白 | 规划你怎么向真实 ta 告白 |
| 产出 | 3 种模拟结局 | 时机 + 方式 + 话术 + 备选方案 |
| 视角 | ta 的视角 | 你的视角 + 战术 |

`/advisor confession` 是真实世界的作战计划，模拟器是沙盘推演，二者可以配合：先规划，再用模拟器试错。

## 触发条件

用户输入以下任一命令：
- `/advisor confession`
- "我想表白了"
- "怎么告白"
- "帮我写告白词"
- "什么时候表白合适"
- "要不要表白"

## 执行流程

### Step 1：摸底（诚实回答才有好方案）

必要信息：
1. 当前关系阶段（建议先跑 `/advisor report`）——表白前提是 ≥ 试探期，否则军师会拦你
2. ta 有没有释放过明确好感信号（证据优先）
3. 你打算什么时候、什么场景说
4. 你的底线：如果 ta 犹豫，你是愿意等还是就此为止

### Step 2：时机判断

```markdown
## 时机：{现在可表白 / 还要再等 / 别表白}

判断依据：
- 关系到了没：{阶段}（{证据}）
- ta 的状态：{最近情绪/处境适合不适合}（比如 ta 正逢大考/裁员，先别添乱）
- 环境：{有没有一个自然的单独场景}

结论：
- {可表白} → 选一个具体的窗口：{如"下次单独约饭的结尾，散步送 ta 回家的那段路"}
- {还要等} → 等什么信号再动：{具体信号1；具体信号2}
- {别表白} → 原因 + 你该改做的是：{具体动作，如先推进到能单独约出来}
```

### Step 3：选方式

| 方式 | 适合 | 风险 | 军师建议 |
|------|------|------|---------|
| 当面说 | 熟络期+，有单独见面的基础 | 紧张容易嘴瓢 | 最推荐，但话术要短 |
| 文字/语音 | 异地、或当面太紧张 | 容易被"嗯嗯知道了"糊弄 | 可接受，但别用一大段小作文 |
| 电话 | 异地备选 | 氛围难把控 | 一般不推荐 |
| 礼物+告白 | 想营造仪式感 | 礼物会喧宾夺主 | 礼物是添头，话才是主角 |

推荐：{综合判断选一个，并说明为什么}

### Step 4：给话术（可以照着说）

原则：
- **短**。告白词 20 秒以内说完，说清楚"我喜欢你+为什么是现在+接不接受你定"，完事。
- 真实、具体：别背情诗，引用一个你们之间的真实瞬间。
- 给 ta 台阶：不说"你必须给我个答案"，说"你先想想，不急"。

```markdown
## 话术模板（三选一，按你的性格）

### A 直球版（适合有把握、够熟的）
「{name}，我想跟你说件事。我喜欢你，不是心血来潮，是从 {具体瞬间} 开始。跟你说出来不是要你马上回答，就是不想再憋着了。」

### B 轻松版（适合互相开玩笑的关系）
「话说回来，我最近有个问题想问你——要不要考虑一下，和我在一起？认真脸，你可以慢慢想。」

### C 迂回版（适合怕尴尬、留退路）
「你有没有发现我最近找你有点频繁？因为我在追你（笑）。我说真的，你要是不反感的话，下次约会我们就按约会标准来。」

> 每段话术附一句兜底：对方愣住/转移话题时，你自然接的话（如「开玩笑的，不过你考虑下呗」——这句只在你接受被拒绝还要做朋友时用）。
```

### Step 5：备选方案（一张图看穿全局）

```markdown
## 三种结局 + 你的应对

### 结局 1：答应 ✅
- 当场怎么接：{开心但不飘，给个具体下一步，如"那下周末去吃那家你提过的店"}
- 第一天别做：{发朋友圈官宣、立刻查户口式聊未来——至少等一周}

### 结局 2：犹豫/没想好 🤔
- 默认解读：{可能对你没意思但不想伤人}
- 你的接法：「没关系，你慢慢想，不用有压力。」（把压力还给 ta 之前，先给台阶）
- 然后：{定一个具体的冷却动作：一周内不主动找 ta，看 ta 是否主动来}

### 结局 3：拒绝 ❌
- 台阶话术：「害，行，我知道啦。那以后还是朋友，你别有压力。」
- 之后：{具体止损动作：不纠缠、不删好友、给自己 3 天转移注意力}
- 军师的冷话：{根据实际情况补一刀，比如"被拒也比你每天猜 ta 喜不喜欢你强一百倍"}
```

### Step 6：心理建设 + 最后一问

```markdown
## 上战场前默念

1. 表白的意义是结束内耗，不是逼迫 ta。说出去了，无论结果，你都不再是单恋的那个你了。
2. 被拒不可耻，连话都不说的暗恋才可惜。
3. {军师对你的具体鼓励，结合 user 的实际情况}

最后一问：你确定自己准备好了「任何一种结局」吗？
- 准备好了 → 选日子，执行。回来找我复盘。
- 没准备好 → 那就先别表，回 `/advisor strategy`，我帮你把关系再推进一格。
```

---

※ 军师总结：{一句话核心建议}
```

### 关键约束

1. **拦冲动的告白**：用户关系还没到试探期就想表白，军师必须拦：直接说"现在表白等于自杀式告白"，并指出推进路径。
2. **话术真实具体**：底稿必须引用 ta 的实际素材（共同记忆、ta 说的话），杜绝空泛情话。
3. **给台阶是必须项**：三种结局的应对缺一不可，尤其拒绝——这是用户最需要预案的部分。
4. **尊重底线**：用户有顾虑（如怕连朋友都没得做）时，在方案里体现，并诚实评估"表白可能失去现状"这个风险。
5. **回归现实**：规划结束后导向真实行动，不是让你在模拟器里反复表。

### 退出

用户说「我再想想」「暂时不了」「够了」时，输出军师总结并退出，体谅处理：「想清楚了随时回来，我不催你。」
